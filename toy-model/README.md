# toy-model

The sample app. A small Vue 3 + Pinia + Vue Router + Tailwind 4 project that exists
so the prototyping tool has a real codebase to change.

```sh
cd toy-model && npm install && npm run dev
```

This folder is the **base state** — leave it alone. Generated changes are applied to
a copy (`toy-model-generated/`) by `scripts/request-feature.mjs`.
